# StyledIcon

`StyledIcon` creates theme-aware icons from bundled icon fonts and can apply palette roles, fixed colors, modifiers, and badges. For practical selection and styling patterns, see {doc}`Using icons in plugins <../../../../development/building_plugins/icons>`.
