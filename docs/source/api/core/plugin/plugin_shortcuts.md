# PluginShortcuts

This class is for documenting plugin shortcuts (used to display a shortcut map in the UI). 

```{note}
This is merely for *documenting* shortcuts, it assumes the plugin developer has already established the shortcut handling in their own code.
```

For binding and documenting the same sequence, choosing shortcut scope, grouping entries, and handling shared factory state, see {doc}`Documenting plugin shortcuts <../../../development/building_plugins/learning_center/shortcuts>`.
