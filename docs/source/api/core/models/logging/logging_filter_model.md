# LoggingFilterModel

**Qualified name:** `mv::LoggingFilterModel`

`LoggingFilterModel` is the sorting and filtering layer for a {doc}`LoggingModel <logging_model>`. It supports filtering captured messages by text and Qt message type while preserving the structured column semantics needed for sorting.
