# Planning

Planning types describe a workflow before it runs. `WorkflowPlan` owns the stage and job graph, handles identify its entities, and option value types configure cancellation, parallelization, batching, profiling, and reporting at the execution boundary.

For design guidance, see {doc}`Defining workflows <../../../../development/workflows/defining_workflows>`.
