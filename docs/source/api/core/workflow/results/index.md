# Results

Result types describe outcomes at workflow, stage, and job level. The root result contains collected messages and metrics, while the future and registry support asynchronous observation and later presentation.

For result interpretation and failure behavior, see {doc}`Results and error handling <../../../../development/workflows/results_and_error_handling>`.
